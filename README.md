# Indigenous Business Loan Portal

## Project Overview

The Indigenous Business Loan Portal is a secure cloud-based web application that allows Indigenous business owners to register, authenticate, submit loan applications, view application status, and update profile information.

## AWS Services

- Amazon Cognito
- Amazon API Gateway
- AWS Lambda
- Amazon DynamoDB
- Amazon S3
- Amazon CloudFront
- IAM
- AWS SAM
- GitHub Actions
